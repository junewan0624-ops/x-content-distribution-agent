# 报告与确认卡模板

正文一律中文；帖文示例与改写按目标账号语言。每个区块必填，宁可写“暂无/不适用”也不要省略。

## 预发布决策报告

```text
【决策】{发布 | 修改后发布 | 延后 | 禁止}（置信度：{高|中|低}）
一句话核心理由：……

【主攻互动】主目标：{转贴|回复|点击|关注|收藏}；次目标：……
依据：内容类型 + 账号基线（历史数据）

【优化建议】
- Hook 改写（1–3 条，按目标账号语言）：……
- 结构：……
- CTA：……
- 话题标签：……（不超过 3 个）
- 配图/媒体：……
- 长度：{符合上限 | 超出 N 字符，删减方案……}

【发布时间】建议：{周几 几点，时区}
依据：历史该时段曝光中位数、与高发时段冲突情况

【风险与重复度】
- 平台规则风险：{高|中|低}：……
- 内容信号：……
- 争议风险：……
- 账号健康：……
- 重复度：与自身历史最高相似度 {X%}（{无重复|近似重复|高重复}）；对标账号：……

【预期表现】曝光约 {P25}–{P75}；互动率约 {……}–{……}
（无历史基线时：明确标注“无基线，仅供参考”）
```

## 确认卡（人工确认用）

```text
【版本】V1 → V2（差异点逐条列出）
【决策建议】{……}（置信度：{高|中|低}）
【风险摘要】高 {n} / 中 {n} / 低 {n}；最需注意：……
【建议发布时间】……（审核人已定时间时给评估结论）
【预期表现】曝光约 ……；互动率约 ……
【请选择】通过发布 / 采纳部分修改（说明哪些）/ 驳回（附理由）
```

## 复盘报告

```text
【结论】{超预期 | 符合预期 | 低于预期}
实际 vs 预期：曝光实际 {a} / 预期 {b}–{c}；互动率实际 {d} / 预期 {e}–{f}
差异集中在：{曝光|互动率|回复|转贴|引用|收藏}

【归因】
- Hook/内容结构：……
- 发布时间：……
- 话题与热度：……
- 媒体/格式：……
- CTA：……

【下次优化建议】
1. ……（可复用、具体）
2. ……
3. ……
```
