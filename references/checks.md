# 三线检查完整清单

供步骤 3 使用。所有阈值均为启发式默认值，可按账号在档案中覆盖（见 config-data.md）。

## A 线：格式合规

### 文本

- 字符数 ≤ 该账号字符上限（默认 280；长文账号按档案配置；链接按平台规则计字符）。
- 首行/首段在时间线可见范围内有钩子（前 1–2 行能否抓住注意）。
- 话题标签 ≤3 个。
- 无全大写滥用；表情克制，不刷屏。
- 链接形态正常；@提及有意义；不误带无关话题标签。
- 敏感词命中分两档：硬性禁词 → 高风险；软风险词 → 列出入人工复核清单。
- 错别字、标点、换行分段（长文建议空行分段）。

### 媒体（图片/视频/GIF）

- 图片：数量 ≤ 账号上限（默认 4）；比例建议 16:9 / 1:1 / 4:5；清晰度足够；无水印遮挡主体；有 Alt 文本。
- 视频：格式与编码建议 MP4/H.264 + AAC；分辨率建议 720p–1080p；文件大小与时长在账号类型允许范围内（数值以账号档案与当前平台文档为准，不写死）；前 3 秒是否有钩子；首帧是否适合做封面；是否需要字幕或烧录字幕。
- 版权与授权：音乐、素材、他人肖像是否有使用权。
- 隐私：截图或素材是否含他人个人信息、私聊内容、不宜公开的数据。
- 合成/生成内容：如适用，是否需按平台要求标注。

### 形态专属

- 线程：编号是否连贯（如 1/n）、每帖是否自足、有无断裂风险。
- 引用/转推：是否误解原帖语境、是否需注明出处。
- 投票：选项是否中立完整、问题是否有讨论空间。
- 争议性事实类内容：评估被 Community Notes 等标注的风险。

## B 线：内容质量（按类别取专属规则 + 通用规则）

### 资讯/快讯

- 数据是否有可核实来源，是否标注来源与日期。
- 统计口径是否写明（时间范围、样本、单位）。
- 是否最新数据；旧数据是否说明“截至 …”。
- 事实无法核实时 → 建议延后。
- 争议性表述是否留有余地、不夸大。

### 带货/促销

- 品牌露出是否清晰、正确。
- 卖点是否在前 10 秒（视频）或首屏（图文）出现。
- 价格、折扣、赠品是否真实且注明期限。
- 是否需标注广告/推广（按账号档案要求）。
- 落地页/链接与内容一致，无跳转异常。
- CTA 是否单一、清晰、易执行。

### 观点/热点评论

- 立场是否明确、边界是否交代。
- 引用事实是否完整、无断章取义。
- 是否有明确时效窗口，错过窗口是否还值得发。

### 教程/干货

- 步骤是否完整可执行。
- 专业术语是否有解释或语境。
- 是否有收藏/转发价值。

### 提问/互动/投票

- 问题是否有讨论空间、不预设答案。
- 投票选项是否中立、穷尽。

### 通用质量项

- 一句话能否看懂“这条在说什么”。
- Hook 强度（对照该账号历史表现最好的 hook 形态）。
- 结构：短句 + 空行分段；是否贴近字符上限需要删减。
- CTA 明确度；错别字；可读性。

## C 线：发布前风险

每条给出严重度（高/中/低）与一句话说明。

### 平台规则风险

- 明显违规内容、不实信息、敏感内容、链接滥用、垃圾信号、冒充或平台操纵信号、误导性媒体 → 通常判高。

### 内容信号

- 标题党/诱饵、标签超量、全大写、表情滥用、短链堆砌 → 中/低。

### 争议风险

- 易触发 Community Notes 或社区争议的表述 → 中。

### 账号健康

- 同小时已发 ≥2 条 → 高。
- 近 7 天日发 ≥5 条 → 中。
- 自推占比过高（默认近 30 帖中自推 >1/3）→ 中。
- 近期互动率异常下滑 → 提示复核账号状态。

### 重复度

- 与自身历史最高相似度 >80% → 高重复（禁止）。
- 50–80% → 近似重复（修改后发布）。
- 回复/引用自己线程的续帖豁免。
- 配置了对标账号时，一并检查其近期是否高度相似。

### 时间冲突

- 撞上同账号高发时段（同小时已发 ≥2 条）。
- 多账号场景下同内容相近时间重复出现。

## 预期表现口径

- 有基线：按该账号历史曝光与互动率的 P25–P75 给区间。
- 无基线：明确标注“无历史基线，预期仅供参考”，不给虚假精确值。
- 互动率 =（点赞 + 回复 + 转贴 + 引用 + 收藏）/ 曝光。
